# Expense Tracker

A simple React + Firebase expense tracker with email/password authentication, email verification, and password reset. Track spending, filter by date, and manage expenses in one clean dashboard.

## Quick Start
- Install: `npm install`
- Dev server: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`
- Lint: `npm run lint`

## Features
- Firebase email/password auth with verification and reset
- Protected routes for verified users
- Expense CRUD with date filtering

## Tech Stack
- React + Vite
- Firebase Auth + Firestore
- CSS Modules
